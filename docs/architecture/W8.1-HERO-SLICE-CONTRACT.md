# W8.1 — Hero Slice Contract

Date: 2026-10-08

Status: **LOCKED**

## Mission

Improve the sensory quality and presentation of Mass Runner without changing its accepted gameplay semantics or the Game Factory architecture.

W8.1 is a controlled A/B experiment:

```text
same level
same model
same route
same platform
        |
 baseline vs polished presentation
```

## Scope

Production changes may be limited to:

`src/games/mass-runner/**`

W8.1 may also add tests, capture tooling, research/evidence and phase workflow files.

Protected production code:

- `src/core/**`
- `src/platform/**`
- `src/runtime/**`
- `src/testing/**`
- `src/factory/**`
- prior proof-game families

Expected protected production churn:

`0`

## Gameplay invariants

W8.1 must not change:

- level content;
- target masses;
- scoring;
- collision semantics;
- steering semantics;
- forward speed;
- fail/clear logic;
- five-level progression;
- distribution behavior.

## A/B mode

Mass Runner supports:

```text
?presentation=baseline
?presentation=polished
```

Default:

`polished`

The baseline path preserves the W7 presentation for comparison only.

## Implemented presentation stack

The polished path may add:

- squash/stretch;
- steering lean;
- secondary wobble;
- dynamic shadow;
- afterimage trail;
- lane speed streaks;
- pickup glow/particles;
- floating result text;
- gate world labels;
- good/bad color hierarchy;
- positive/negative flash;
- deterministic micro-shake;
- HUD mass pulse;
- clear/final particles;
- CTA pulse.

All effects are deterministic or driven solely by accepted gameplay state.

## Audio boundary

W8.1 does **not** add production audio.

Reason:

W6 already established platform audio-enabled state. Adding one-off WebAudio inside Mass Runner would bypass that boundary.

W8.2 will implement the locked sound palette through an audio path that obeys platform mute state.

## Evidence

Mandatory:

- existing full verification PASS;
- presentation unit tests PASS;
- protected production churn = 0;
- baseline and polished videos generated from the same route;
- opening, gate-impact and clear screenshots for both modes;
- artifact budget PASS.

Expected marker:

`W8_1_HERO_SLICE_PASS`
