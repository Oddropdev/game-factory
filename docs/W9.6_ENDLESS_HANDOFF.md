- Source: `w9-6-endless-worlds`; draft PR #39 stacked on the isolated W9.5 mobile preview PR #38.
- Game mode: `?mode=endless&seed=17` (seed optional). Use `?mode=trilogy` for the completely unchanged W9.5 three-world acceptance game.

- Never merge this release-candidate branch into `main` without review.
- The public Pages build contains only generated/unlicensed materials; owner-only purchased ITHappy models are not uploaded.

## What actually changed
- Crystal → Candy → Rainbow remain the original first three stages; Rainbow no longer terminates the run in endless mode.
- World 4 starts at progress 1340m; subsequent generated worlds have 220m roads and 180m magnetic journeys, with 400m stride.
- Metadata, hazards, collectible layouts, biomes, road banking and scenery are deterministic functions of (world index, run seed).
- 10 biome families with different color palettes and actual decorative silhouettes; world-specific seeds, large-scale bends, obstacle counts, arch placement and banked roads prevent plain color cycling.
- Independent per-world physics staging and disposal from W9.5 are preserved. Next world is only prepared after entering a safely constrained transit. The ball holds rather than ejecting if staging fails.
- Spectacle coaster generator attempts broad horizontal S-curves or helix profiles with height variation; uses the preexisting clearance, radius, tangent and port validator, with a safe verified fallback.
- Difficulty grows to tier 10 and stays bounded. The progress bar describes the current world rather than saturating at 1160m. World counter remains visible.

## Automated evidence and limits
- Unit simulation generates Worlds 4–1000 and validates road bounds, layout diversity, monotonic ports, tier cap and world 137. This is **not** a 1000-world live Chromium/Android run.
- Real Chromium test in `tests/ball/w9-6-endless.spec.mjs` drives the original Bullet ball from World 1 across five real tube transitions into World 6 and checks disposal, collisions, camera, and absence of early finish. CI will block release unless it passes.
- Only a physical phone playtest can approve touch feel, true FPS/heat and long-lived resource consumption.
- Existing W9.5 trilogy remains available by URL query parameter as an immediate comparison.

## Mobile review
Try the published endless URL in Android Chrome and verify that it moves **past** Rainbow Rush; note how curved Journey A/B feel, camera angles through large bends, start/finish continuity and any judder in World 4+. Video feedback is ideal if a defect is encountered.
