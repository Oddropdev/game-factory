## What changed visually

- Prior +/× gates were literally PlayCanvas box beams and straight box
  posts. They are now framed with genuine rounded **capsule** 3D meshes,
  soft corner highlights and a cream/gold accent crown.
- The left/right portal material is now selected by the actual
  `applyMassOperation` benefit (not by fixed lane order). Text labels
  still reflect authoritative clamped mass delta; e.g. at minimum mass,
  an otherwise negative gate can correctly display `+0`.
- Previously hard-edged lane slab and rails now use a curved capsule
  road surface, rounded road lips and glowing soft streaks.
- Hazards now use rounded roller/cap shapes, not sharp red blocks.
- Reward text is positioned lower so it does not cover upcoming arithmetic
  gate choices; new screenshot and CSS legibility checks pass.
- A smooth mascot from W9.3-1 remains unchanged and highly visible.
- Full viewport remains occupied; images show real player, course,
  portals and +/− decisions instead of an empty WebGL canvas.
