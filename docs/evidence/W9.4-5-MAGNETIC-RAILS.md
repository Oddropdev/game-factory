# W9.4-5 Magnetic Boost Rails — Long Curve Hero Pass

Status: TECHNICAL BROWSER PASS — private-asset visual and physical Android approval pending
Base: `main` at `8b99a5f8dfda2a4eb6b41065cda6e517043475a8`.

## Mission
Keep the fast sky ball physics and long 440m jump course. Introduce
**three long rails on the outside of bends**, not roadside
rails everywhere, each glowing green on a real Bullet contact.
Contact pushes the ball forward, with a small magnetic approach pull
TOWARD the chosen rail and downward adhesion before impact.

## Implementation
- New opt-in `/ball/?mode=rail`; original `/ball/`, `?mode=speed`
  and `?mode=jump` unchanged and covered by regressions.
- Segmented overlapping real STATIC Ammo boxes, height 1.48m,
  positioned along the outside of long curves:
  - Right-hand arc: 29–81m (52m)
  - Left-hand arc: 100–157m (57m)
  - Long right-hand return: 339–394m (55m)
- Attraction bounded by 100N, adhesion <=64N down; forward
  contact acceleration bounded at 155N and capped by the
  existing 64m/s rail-mode top speed.
- **Crucial distinction:** proximity enables gentle approach
  magnetism, but the forward rail bonus requires a real collision
  event from the dynamic ball contacting a real rail collider.
  No forced teleport, hidden path correction or speed counter faking.
- Emissive green shared material per section brightens only after
  contact; sixteen pooled tiny emissive spheres implement contact
  sparks without allocating new visual objects on each frame.
- A non-contact centered run must have zero rail boost, glow or
  spark. Rail contact must accelerate, downforce must be applied,
  and lateral input can still disengage.
- Read-only browser telemetry tracks contact events, approach ticks,
  time boosted, force-integrated potential delta-V, glowing section,
  spark count and observed physical planar speed.
