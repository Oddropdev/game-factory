## Visual identity hypothesis

- Shape language: connected, smooth, rounded **toy/soft-form** silhouettes;
  never imitate this with smoothed cube normals alone.
- Avatar: mint gummy mascot with softly connected capsule-like body/limbs,
  large rounded face/head, oversized stylized eyes and compact shoes.
  Friendly but recognizable, not a plain ball and not blocky Kenney mesh.
- Avatar accents: warm cream, coral blush, lilac shoes, honey-yellow tuft
  and chest badge.
- Avatar surface: subtle gloss and diffuse highlights, restrained emissive.
  No chrome/metal, exposed wireframe or pixel/voxel edges.
- Genre reference: soft hypercasual 3D like Tall Man Run / Going Balls.
  References are style cues, NOT licensed game assets to copy.
- Track and portals remain frozen for W9.3-1; they are explicitly marked
  as **not yet conforming** and addressed by W9.3-2.
