## Private installation (Windows; one small ZIP)

The owner downloads `W9.4-2_ITHappy_Selected_Private.zip` from the ChatGPT
conversation into Downloads. From a local game-factory checkout (after PR is
merged), run:

```powershell
git pull --ff-only
powershell -ExecutionPolicy Bypass -File .\tools\install-w9-4-ithappy.ps1 -SelectedZip "$env:USERPROFILE\Downloads\W9.4-2_ITHappy_Selected_Private.zip"
npm run build:w9-4:ball
```

Installer extracts only six exact versioned files, verifies **SHA256**
and GLB magic, and writes them to the gitignored
`spikes/w9-ball/public/licensed/` folder. It sets
`spikes/w9-ball/.env.local` (`VITE_ITHAPPY_ASSETS=1`), also gitignored.

Alternative: installer without `-SelectedZip` reads the two full
original ZIPs from Downloads (exact filenames). No manual extracting.
Run `npm run package:playtest` first if `playtest-dist` is absent;
then `npm run build:w9-4:ball`, and use the existing local preview.

## Engineering design

- If no private art installed, the game builds/runs with the established
  W9.4-1 procedural stand-ins and makes **no /licensed requests**.
- With private art, PlayCanvas `ContainerResource` loads six GLBs and
  instantiates visual children only; physics parent position, size,
  body/torque/velocity, hazard placement and reward loop remain fixed.
- If any GLB fails to load, missing models do not make physical obstacles
  invisible. Browser snapshot tracks artMode, loaded count and physics type.
- Public GitHub excludes the raw art, the local files, the private `.env`,
  and no Pages workflow automatically publishes this build.
