## Correction-loop evidence

W8.1 CI caught several useful test/evidence issues while production semantics remained stable:

1. unused presentation-type import during typecheck;
2. Node/browser typing mismatch in the first capture module;
3. accepted W7 browser route becoming timing-sensitive under richer rendering;
4. exact event-count polling being too brittle for deterministic autoplay;
5. capture start input conflicting with autoplay ownership.

The final solution separates concerns:

- accepted W7 gameplay regression uses a frame-robust input route;
- W8.1 capture uses deterministic autoplay;
- gate evidence waits for the exact authored gate event and freezes the runtime for the screenshot.

No protected production code was changed to repair these evidence problems.

## Audio decision

Production audio remains intentionally absent in W8.1.

The reference pass already locks the W8.2 semantic palette:

- pickup;
- positive gate;
- multiplier;
- negative gate / hazard;
- level clear;
- fail;
- final MASSIVE.

W8.2 must route sound through the accepted platform audio-enabled boundary rather than adding ad-hoc WebAudio inside Mass Runner.
