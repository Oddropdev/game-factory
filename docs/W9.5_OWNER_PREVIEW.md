# W9.5 owner preview

Download the `w9-5-three-worlds-owner-preview` artifact from the draft PR's **W9.5 Three Worlds Preview** check. Extract the whole ZIP and double-click `Start_Three_Levels.cmd`. Node.js 24+ is required. The packaged build needs no npm installation or network after extraction. It opens `http://127.0.0.1:4177/ball/?mode=trilogy`.

Drag sideways to steer; flick up to accelerate. Green guards still support magnetic side/top riding and opposite-swipe release. Train rails only reward riding on top. In each transit, drag sideways to orbit the tube. The exit holds safely while content is unavailable, then resumes automatically. Space restarts the run. A restart reloads the world lifecycle cleanly.

Append `&seed=17` to reproduce the same two coaster layouts. The read-only `window.__W9_BALL_TEST__.snapshot().trilogy` records the actual seeds, geometry fingerprints, loading/activation/disposal events and physics contacts.

## Purchased assets — local repository only

The public artifact uses original generated scenery and contains no paid GLB or ZIP files. In your repository checkout, double-click `Install_Private_Art.cmd` and select your two purchased GLB ZIPs. It verifies nine source hashes and installs only those models into the ignored local `public/licensed` folder. The script rebuilds the owner preview. Then run `Start_Three_Levels.cmd`.

The installer preserves the existing verified six-model workflow and adds a decorative arch, balloon and coin. Source materials and transforms remain inside cosmetic children. Road colliders and the original Bullet ball stay authoritative. Missing optional models retain visible original substitutes. Raw purchased models must never be committed or included in distributed archives.

For an explicitly unlicensed build, run `npm run build:w9-5:public`. Its allowlist excludes private models even when they are installed locally, and a separate check rejects GLB/ZIP/private paths in the output.
